Ниже — полностью рабочий, автономный `index.html` в одном файле, реализующий интерактивную платформу для изучения Python в стиле freeCodeCamp. Всё на чистом HTML5, CSS (Tailwind CDN), JS; Python выполняется через Pyodide, редактор — CodeMirror 6, тесты — через `assert` внутри Pyodide. --- ## Что реализовано - **Архитектура 3 колонок (адаптивная):** левая — навигация и теория, центр — редактор кода, правая — консоль и статус тестов. - **Движок Python:** Pyodide (запускается асинхронно, кэшируется в браузере). - **Редактор:** CodeMirror 6 с подсветкой синтаксиса Python. - **Тесты:** скрытые тест-кейсы в виде `assert`-выражений, запускаются в Pyodide; вывод stdout/stderr отображается в консоли. - **Прогресс:** автосохранение в `localStorage` (выполненные уроки, код для каждого урока). - **Курс:** 4 фундаментальных модуля, первые 3–4 урока — с полноценной теорией, стартовым кодом и тестами; остальные — каркас на JSON-массиве для масштабирования. ```html Python Academy — интерактивный курс
